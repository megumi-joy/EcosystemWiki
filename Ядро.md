# Ядро — обучающийся проверяльщик

**Чем является.** Исследовательская программа: система, которая учится
по школьным учебникам как школьник и отвечает ИМЕНЕМ правила («это
гравитация», «это перенос слова»), а не похожей картинкой. Три исхода
на любую задачу: назвала закон, задала адресный вопрос, отказалась —
незнание не выдаётся за ответ.

**Что закрывает.** Будущий проверяющий для [Обучения](Обучение.md):
чтобы записать умение в паспорт ступени «проверено системой», нужна
проверка, которую нельзя обмануть заученным ответом. Ядро строится
ровно на этом требовании: каждое его правило обязано пережить проверку,
которую могло провалить — подстановку корня, подделанные данные,
невиданную половину задач.

**Связи.** Учится на фактах украинских школьных учебников (изданных за
государственные средства; тексты не перепубликуются — берутся только
факты языка и порождённые задания). Проверяется на открытых наборах
задач и на человеческих описаниях. Продуктам отдаёт готовые куски:
генератор уроков LingoQuest — первый перенесённый.

**Состояние.** Исследование: читает буквы с невиданных шрифтов, делит
слова на слоги выведенным (не вписанным) правилом, решает уравнения
первого класса из настоящих книг с проверкой подстановкой, само вывело
закон падения из кадров сцены. До проверяющего в паспорте — далеко, и
это написано честно.
