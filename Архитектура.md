# Архитектура

## Круг ценности

```
учащиеся и фрилансеры
        │ проверенные результаты
        ▼
   паспорт знаний ──── обучающие данные ───▶ ИИ-сервисы
        ▲                                        │
        └──────────── ценность возвращается ◀────┘
```

## Что попадает в реестр

```
проверка (устно / от руки / зачёт документов) ──хеш──▶ публичный реестр
учащиеся ──выступают как──▶ валидаторы и арбитры ─────▶ публичный реестр

публичный реестр ──▶ EStableCoin — стабильная, эскроу 24 часа, обратимая
                 ──▶ EFlexCoin  — плавающая, за микровклад
                 ──▶ управление: дополнения обновляют систему

EStableCoin ──▶ образование, фриланс, общественные услуги
```

В реестр попадает хеш результата проверки, а не содержание работы.

## Не определено

- формат записи дополнения в реестр;
- что именно хешируется в результате проверки;
- как ступень паспорта проверяется контрактом при выдаче прав.
